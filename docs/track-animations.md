## 实机协议事实（一切以此为准）

**行为级协议（2026-08-18 抬轮直测，用户在两台机器人上执行，方法：串口直发命令观察履带）**：

| 串口命令 | 实机行为 |
|---|---|
| `X±n` | 前进/后退 n%（X100 = 满速前进，直测确认） |
| `Y±n` | 原地左转/右转 n%（Y+100 = 左转，两轮反向） |
| `X0` + `Y0` | 停止 |

物理混控公式：`左履带 = X−Y`，`右履带 = X+Y`。

**成因（2026-08-20 裁决）**：实机固件就是 upstream `378573d` 原版（用户自行烧录），但**左电机接线极性反接**——指令层固件代码 X=转向/Y=前后，经反接的左电机在物理层翻转，最终行为即上表。这是唯一同时解释三组观测（X100 直行 / Y100 左转 / X50+Y86 贴身小圈）的模型。

标定锚点（2026-08-18 实测，用户执行）：
- `Y100` 原地自转 360° = **10.0s**
- `X50`+`Y86` 贴身回转 360° = **19.0s**

⚠ **不要"修正"左电机接线**——反接是既有承重状态，动它整个协议翻转、全部标定作废。
⚠ **固件重烧规则**：只能基于同一 upstream 基线且不改 X/Y 混控语义的版本；重烧后必须重跑轴向测试（发 `X100` 应前进）。本项目常规迭代不动固件，烧录需用户明确批准。

## 为什么废弃了旧的 w/q 脉冲方案

旧方案（walle_drive.py / 旧 track_animations.py）用"满速 w 通 0.18s / q 停 0.12s"的脉冲模拟慢速。后果链条：每 0.3 秒一次满扭矩堵转级电流冲击 → 12V 轨电压反复下坠 → UNO 欠压复位（ttyACM0 重枚举）→ Pi 侧串口线程处理不当 → **整台 Pi 假死**。X/Y 模拟量命令让固件做平滑梯形加减速，从源头消除冲击；网页摇杆多年来就是这条路径，从未触发问题。

## 旧动画设计记录（性格节拍，供新表对照）

7 段角色动画的核心是"用节奏表达性格"而非动作种类：

| 动画 | 性格节拍（旧 w/q 版设计意图） |
|---|---|
| curious | 慢蹭→停住张望→探一下又缩回→左右看→犹豫再蹭→下定决心冲刺 |
| startled | 受惊急退→慌忙左看→猛甩 225° 掉头→全速逃离 |
| patrol | 正方形巡逻：直行→到角停下"压实检查"→右转 90°，×4 |
| puppy | 蹦两步→开心转一整圈→反向再一圈→再蹦→再转 |
| excited | 小碎步抖动×6→急转一圈→再抖×4→压抑不住冲刺 |
| hesitant | 进一步退两步×2→左右张望纠结→慢慢起步→加速 |
| spin | 右转一圈→左转一圈 |

新表（2026-08-18 版）逐段保留了这些节拍，仅把"满速+脉冲"换成模拟量速度（curious 慢蹭=X40、巡逻巡航=X70、冲刺=X100 等）。**2026-08-24 实验锁定版已整体替换为下表**，patrol/puppy/excited/spin 不再存在：

| 动画 | 行为原型（2026-08-25 差异化轮） | 主导维度 |
|---|---|---|
| curious | 检视垃圾堆/陌生物件：**多地点巡视**——走→宽幅扫视（45/90/45°）→换地点走长段→再扫→再挪→停下打量→末瞥 50° 回正（单向趋近，无后退；08-27 归零轮补偿帧） | 位移（走-看-走-看） |
| hesitant | 面对EVE的趋避试探：进退 2 轮（4 拍）→三次张望纠结→下定决心起步加速 | 进退节律+决策弧 |
| startled | freeze→后缩→两次清晰张望→转身 180°→**前进**冲刺离场→猛回头 180° 面对威胁定格（间隙 ≥0.35s；08-27 归零轮加回头拍，动物行为原型） | 爆发叙事 |
| eager | 兴冲冲趋近 + playful：碎步×3→右扫 90°（08-27 归零轮由 35° 放大）→**贴身弧线 90°**（"绕一下继续跑"）→冲刺 1s | 速度对比 |
| solitary | 独自前行：低速**长走**（3.5/2.8/2.0s，位移翻倍）+停顿，刻意不张望（pilot：观感好但原时长位移不可见） | 时间/匀速 |
| shy | 候选·害羞靠近：**侧身弧线**——偏头 35° 回避视线→贴身弧线 45° 绕行→蠕行→怯一下→再弧线 30°→蠕行到底→转回来停在目标旁边（净朝向 ≈+5°） | 空间策略（弧线） |
| wiggle | 候选·开心扭扭（**蛇形版**）：进场小冲→**连续 S 形弧线扭摆**（X15+Y85 混控，左甩右甩 ×6，相邻甩拍不留停顿、流动感即目的）→换气→收尾窜步定格；净朝向归零 | 弧线混控（蛇形） |
| discover | 候选·发现东西：巡航→猛停→大退换视角→**右 60° 端详→再走→左 130° 绕到另一侧**→DRIFT 极慢凑近→长静止研究→默默退走→回望（08-27 归零轮补偿帧） | 旋转（单物件环绕） |
| calibrate | 工程标定序列（见"重新标定"节，不属于实验素材） | — |

## 新引擎用法

- 文件：`web_interface/track_animations.py`，零第三方依赖
- 动画 = `(x, y, 保持秒数)` 关键帧表，结构对齐原作者 `animations.ino` 的声明式写法
- 每帧双轴全发（状态幂等，断线重连不残留旧目标）
- 网页：Animate 标签页 → TRACK ANIMATIONS 卡片（时长由后端实时求和渲染，改表自动更新）
- **手动输入优先**：动画播放中任何摇杆/手柄输入会立即抢占并停止动画（2026-08-20 交叉评审后的行为变更）
- 串口断线时动画连续 3 帧发送失败即自动中止（不从断点复活，避免残缺节拍）；`journalctl` 可见播放/打断/中止日志
- `VARY` 开关（默认关）：逐比特相同的重放读作"录音机"，开启后每帧时长 ±8% 扰动。⚠️ **A/B/C 外观实验期间必须保持关闭**——三条件逐帧一致是实验效度的唯一硬约束，开启 VARY 即摧毁它；开发调试时才可开。

**重新标定**（换地面/速度变化后）：只改文件头两个常量——`SPIN_360_SECS`、`PIVOT_360_SECS`，所有转弯时长自动重算。改完先跑 Calibration Run（~38.1s）验证：直行走线要直、自转 5s 应 180°、右向自转 2.5s 应 90°（方向对称性检查，左电机反接背景下左右角速度可能不对称）、自转 0.69s 应 25°（小角度线性度，>2° 同号偏差才需要立项补偿）、贴身 9.5s 应 180°、贴身 2.38s 应 45°、贴身 1.58s 应 30°（SHY 弧线用小角度段）、X40 与 X35（DRIFT）慢行履带应能动。

**实验前必标定项（2026-08-24 pilot 已全部关闭）**：① DRIFT 能动性——**X30 已实机验证可动**（pilot 实测，SOLITARY 走行连续），档位随后调至 **X35** 增大位移可见度（夹在已验证档 30/40 之间，CALIBRATE 的 DRIFT 段现验 X35）；② IDLE 最小可见 Y——**Y±8/±6 完全推不动**（idle 已于 2026-08-25 删除，此条仅作历史记录）。CALIBRATE 里的小角度线性度段现为 **25°** 与贴身 **30°**（全表最小实用角）。**首条实验素材录制后，全表常量即冻结**——中途换档会造成三条件素材不一致，那才是真正的 confound；候选池现为 **8 行为**（锁定五 + shy/wiggle/discover），idle/peek/burst/home 已剪枝（见下），定稿确认须在冻结前完成。

**加新动画**：在 `ANIMATIONS` 字典加一张表 + `DISPLAY` 加显示名，按钮和时长自动出现。速度档位单调递增是性格词汇表：`drift(35) < creep(40) < slow(48) < probe(55) < cruise(70) < sprint(100)`，冲刺用于 startled 的回缩离场、eager 的爆发帧、wiggle 的进/收场点睛。实验抽取用 `EXPERIMENT_ANIMATIONS`（候选池 = 锁定五行为 + 候选三行为，calibrate 等工程序列已排除；**定稿确认前不要开录**）。

**实验规程注意（2026-08-25 交叉评审新增；2026-08-27 归零轮更新运动范围条目，代码层无改动）**：
- **运动范围（08-27 归零轮后）**：所有表净朝向 = 0（±5°），连播/循环**朝向不再漂移**；位置上每轮沿起始朝向净前进约 40-80cm（X100 线速度未标定，按 3-6cm/s 区间估），单段最大伸展半径 ≤10-20cm。实验每 trial 机械复位照旧；演示连播见"运动范围保证"节
- **电量/锚点校验**：自转锚点是双电机重载工况，电量下降会系统性缩水运动幅度；每条件块前充至同电量档并重跑 CALIBRATE 两锚点校验，条件顺序 counterbalance
- **残缺 trial 作废**：串口连续 3 帧失败动画静默中止（UI 进度条仍走满）——凡 journalctl 出现 aborted/serial 警告的 trial 作废重跑
- **时长方差**：eager 11.0s ~ discover 22.9s 差 ~2 倍（08-27 归零轮后；原 4.9~30.1s 差 6 倍）；时长仍是可学习 cue——建议随机呈现顺序 + 分析时以时长为协变量，或避免识别式任务提问
- **剪枝记录（2026-08-25 蛇形轮定）**：idle（基线改由"不发命令"承载，方法学需注明）/ peek（与 curious 重叠）/ burst（与 eager 同 sprint 档同"兴奋"构念）/ home（与 solitary 重叠）；保留 shy（弧线绕行全池唯一）、wiggle（蛇形混控全池唯一）、discover（旋转支配环绕，与位移支配的 curious 分工）

**位置包络**（解析参考值；直线速度未标定，按 X100 = 3~6cm/s 区间给值）：
- 单段：最大伸展半径 ≤334u = **10~20cm**（curious 最大；含末瞥）。
- 整轮连播（UI 卡片顺序 = 推荐连播顺序）：单轮足迹 ≈ 617×511u、净位移 ≈ 310u（4.5cm/s 档 ≈14cm）；4 轮总足迹 ≈ 799×796u ≈ **36×36cm**，第 4 轮末回到起点附近。

**操作规程**：
1. 实验 trial：照旧每 trial 机械复位并记录位姿（归零轮后复位只需对齐位置，朝向自动可信——仍建议按记录核对）。
2. 演示连播：按 UI 卡片顺序从上到下逐个点；连播呈 4 轮近似回环，复位节点按实机观察定（用户实测编排优先，解析推算仅作参考）。
3. 任何动画播放中摇杆可随时抢占（v2 行为不变），越界前手动接管兜底。

**遗留标定项（不阻塞明日实验）**：① X100/X35 直线速度一次卷尺测量（两条间隔 40cm 胶带 + 秒表即可），把上表 u 值换算成硬 cm 数；② wiggle 蛇形对称性依赖左右转向角速度对称（左电机反接背景下未验证）——跑一次 CALIBRATE 的"右向 90°"对称性检查段，左右明显不等时报告数值，用甩拍时长配平。

## 安全机制

1. 动画线程 `finally` 必发停机帧，带 5×0.1s 有限重试
2. `play()/stop()` 单飞锁，同时最多一个动画线程
3. 串口重连/断开时清空命令队列并补发 `X0/Y0`——防止断线期间堆积的旧运动命令重放到复位后的 UNO 上（交叉评审 P0 修复）
4. 串口 `timeout=0.1, write_timeout=1` + `join(timeout=5)`——防 USB 半死永久阻塞线程（旧版冻 Pi 的"放大器"）
5. STOP TRACKS 按钮 = `/track/stop`：立即停动画 + 停机

## 部署到 Pi

```bash
# Mac 上确认分支
cd walle-replica && git checkout track-xy

# 同步到 Pi（二选一; Pi 地址见工作区 IpList.txt, 仅实验室网络可达）
scp -r web_interface/{app.py,track_animations.py,static,templates} pi@<pi-ip>:<Pi上的工程路径>/web_interface/
#   或 Pi 上若为 git 克隆: git fetch && git checkout track-xy && git pull

# Pi 上重启服务并验证
sudo systemctl restart walle.service
#   浏览器打开网页 → 先跑 Calibration Run（抬轮或空旷地面）→ 再玩动画
```

首次验证清单：
1. 抬轮，Settings 确认串口已连接、**deadzone/死区补偿 = 0**（固件存在死区污染 bug，O>0 会导致电机自行加速——历史"X/Y 不稳定"的头号嫌疑）
2. Calibration Run（~38.1s）：直行走线直、自转 180°/右向 90°/25° 段角度准、贴身 180°/45°/30°、X40/X35 慢行能动 → 标定有效（X35 段即 DRIFT 能动性验证）
3. curious 完整跑完，结束时机器人停止端详（v2 结尾不再是冲刺）
4. 播放中点 STOP TRACKS：≤0.5s 停
5. 播放中推摇杆：**动画立即被抢占**，摇杆获得完全控制（v2 行为）
6. **wiggle 首跑抬轮监督**（蛇形弧线零实机记录，甩段内履带满幅反转是全表电气最重事件）：观察 `dmesg` / ttyACM0 无重枚举/复位方可入循环播放（EAGER 碎步同款先例）
