# WALL-E Replica — 分支与定制说明

> 本文档说明本 fork (`JasperJz/walle-replica`) 与原作者仓库 (`chillibasket/walle-replica`) 的区别，以及各分支的用途。

## 分支结构

| 分支 | 用途 | 状态 |
|------|------|------|
| `master` | 主分支：履带动画系统 + motor trim + Mac 本地测试兼容 | 活跃开发 |
| `gesture-recognition` | 备份：OpenCV 手势识别功能（head/neck/eyes/arms servo 控制） | 冻结备份 |
| `upstream/master` | 原作者 Simon Bluett 的仓库（只读，用于同步上游更新） | 只追踪 |

## master 分支 vs 原版 (upstream) 的区别

### 1. 固件层 — `wall-e/wall-e.ino`

**新增：履带独立配平 (Motor Trim)**

```cpp
#define MOTOR_TRIM_L 100   // 左履带速度系数(%)
#define MOTOR_TRIM_R 100   // 右履带速度系数(%)
```

两条履带电机有个体差异（摩擦、电机差），导致直行跑偏。原版两条履带用同一个速度值，改版后可以给每条履带单独乘一个系数。100 = 不补偿（原版行为），调小即可压慢偏快的那条。

### 2. Web 界面层 — `web_interface/`

**新增：履带动画系统 (Track Animation)**

- `track_animations.py` — 履带动画编排引擎，包含 24 种预设动画（forward / backward / left / right / patrol / orbit / figure8 / dance / showcase 等）
- `app.py` — 加了 `/track` 和 `/track/stop` 两个路由
- `main.js` — 加了 `trackAnim()` 和 `trackStop()` 前端函数
- `index.html` — Animation tab 里 servo 动画按钮已注释保留，替换为履带动画按钮

**改动：Mac 本地测试兼容**

`app.py` 做了三处兼容处理，让网页在没有 pyserial / waitress / picamera2 的 Mac 上也能跑：
- `pyserial` 缺失时用空占位，网页仍能启动
- `waitress` 缺失时回退到 Flask 开发服务器
- `picamera2` 缺失时 PiCameraStreamer 自动回退到 Mock

### 3. 独立工具 — `walle_custom/`

- `scripts/walle_drive.py` — SSH 命令行履带测试工具，通过串口直接发送 w/s/a/d 给 Arduino
- `docs/WALL-E-操作手册.md` — 烧录、远程测试、SSH 配置的完整操作手册
- `docs/分支差异说明.md` — 本文件

### 4. 没有改动的部分

以下文件与原版完全一致：
- `wall-e_calibration/wall-e_calibration.ino` — 原版校准程序，未做修改
- `web_interface/templates/login.html`
- `web_interface/static/js/` 下的 automation、joystick 等其他 JS 文件
- `raspberry pi` 部署脚本 `raspi-setup.sh`

## gesture-recognition 分支

这个分支保存了基于 OpenCV + MediaPipe 的手势识别功能（在 master 的 7 个 commit 里）。功能包括：
- 手势识别模块（`web_interface/recognition/`）
- 手掌、拳头、wave、thumb down 等姿态检测
- 通过摄像头实时识别手势并控制 WALL-E servo
- Mac 本地测试脚本和集成文档

如果以后想恢复手势识别功能：
```bash
git checkout gesture-recognition
# 或者 cherry-pick 到 master 上
git cherry-pick <commit-hash>
```

## 多机器人部署

每台机器人的差异点：
1. **Motor trim** — 每台机器人的 `MOTOR_TRIM_L/R` 值不同，烧录前在 `wall-e/wall-e.ino` 里手动调整
2. **Servo 校准** — 每台机器人的 `preset[][2]` 值不同，用 `wall-e_calibration.ino` 重新校准后写入 `wall-e.ino`

部署新机器的流程：
1. `git clone` 本仓库
2. 物理连接 Arduino UNO，烧录 `wall-e_calibration.ino`，校准 servo
3. 把校准值写入 `wall-e.ino`，调整 motor trim
4. 烧录 `wall-e.ino`
5. 复制 `walle_custom/scripts/` 到 Pi，配置 web 服务
